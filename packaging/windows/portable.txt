FlipCraft portable mode

While this file sits next to flipcraft.exe, FlipCraft keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the FlipCraftData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move FlipCraft with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\FlipCraft for settings
and %LOCALAPPDATA%\FlipCraft\Recovery for crash-recovery autosaves. If FlipCraftData can't be
written (for example on a read-only drive), FlipCraft says so and uses those folders instead.
